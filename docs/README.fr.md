# Lasthavens Addon Manager

[en](../README.md) · [ru](../docs/README.ru.md) · [uk](../docs/README.uk.md) · [es](../docs/README.es.md) · [fr](../docs/README.fr.md) · [pt_BR](../docs/README.pt-BR.md)

Gestionnaire local d’addons pour Lasthavens 3.3.5a. Import ZIP, activation, désactivation, mise à jour par réimportation, export et suppression. Les changements nécessitent de recharger le jeu.

Téléchargez le ZIP depuis Releases et décompressez-le. Ouvrez chrome://extensions, activez le mode développeur et choisissez Charger l’extension non empaquetée. Sélectionnez le dossier contenant manifest.json. Ouvrez le gestionnaire, importez un ZIP, activez l’addon et rechargez le jeu.

Les fichiers restent dans le profil Chrome actuel. La suppression conserve les réglages du jeu. Les dossiers intégrés ne peuvent pas être remplacés. La compatibilité de chaque addon doit être vérifiée dans le jeu.

UI: English, Українська, Русский, Español, Français, Português.

ZIP ≤ 32 MB · unpacked ≤ 64 MB · file ≤ 16 MB · library ≤ 96 MB.
