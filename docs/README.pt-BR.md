# Lasthavens Addon Manager

[en](../README.md) · [ru](../docs/README.ru.md) · [uk](../docs/README.uk.md) · [es](../docs/README.es.md) · [fr](../docs/README.fr.md) · [pt_BR](../docs/README.pt-BR.md)

Gerenciador local de addons para Lasthavens 3.3.5a. Importação ZIP, ativação, desativação, atualização por nova importação, exportação e remoção. As alterações exigem recarregar o jogo.

Baixe o ZIP em Releases e extraia os arquivos. Abra chrome://extensions, ative o modo do desenvolvedor e selecione Carregar sem compactação. Escolha a pasta com manifest.json. Abra o gerenciador pelo ícone, importe um ZIP, ative o addon e recarregue o jogo.

Os arquivos ficam no perfil atual do Chrome. A remoção preserva as configurações do jogo. Pastas integradas não podem ser substituídas. A compatibilidade de cada addon deve ser verificada no jogo.

UI: English, Українська, Русский, Español, Français, Português.

ZIP ≤ 32 MB · unpacked ≤ 64 MB · file ≤ 16 MB · library ≤ 96 MB.
