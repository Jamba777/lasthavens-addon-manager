# Lasthavens Addon Manager

[en](../README.md) · [ru](../docs/README.ru.md) · [uk](../docs/README.uk.md) · [es](../docs/README.es.md) · [fr](../docs/README.fr.md) · [pt_BR](../docs/README.pt-BR.md)

Локальний менеджер аддонів для Lasthavens 3.3.5a. Імпорт ZIP, увімкнення та вимкнення, оновлення повторним імпортом, експорт і видалення. Зміни застосовуються після перезавантаження гри.

Завантажте ZIP із Releases, розпакуйте, відкрийте chrome://extensions, увімкніть режим розробника та натисніть «Завантажити розпаковане розширення». Виберіть папку з manifest.json. Відкрийте менеджер через значок розширення, імпортуйте ZIP, увімкніть аддон і перезавантажте гру.

Файли зберігаються в поточному профілі Chrome. Видалення зберігає ігрові налаштування аддона. Заміна вбудованих папок не підтримується. Сумісність кожного аддона потребує перевірки у грі.

UI: English, Українська, Русский, Español, Français, Português.

ZIP ≤ 32 MB · unpacked ≤ 64 MB · file ≤ 16 MB · library ≤ 96 MB.
