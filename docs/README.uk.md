# Lasthavens Addon Manager

[English](../README.md) · [Українська](README.uk.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Français](README.fr.md) · [Português](README.pt-BR.md)

Локальний менеджер аддонів для Lasthavens 3.3.5a. Імпорт ZIP, увімкнення та вимкнення, оновлення повторним імпортом, експорт і видалення. Зміни застосовуються після перезавантаження гри.

![Lasthavens Addon Manager — English interface](images/manager-en.png)

## Встановлення в Chrome

1. Відкрийте [Releases](https://github.com/Jamba777/lasthavens-addon-manager/releases) і завантажте `lasthavens-addon-manager-<version>.zip` із розділу **Assets**.
2. Розпакуйте ZIP у папку, яку зберігатимете на комп’ютері.
3. Відкрийте `chrome://extensions` у Chrome.
4. **Увімкніть «Режим розробника» (Developer mode) у правому верхньому куті.**
5. Натисніть **«Завантажити розпаковане розширення» (Load unpacked)** і виберіть папку з `manifest.json`.
6. У меню розширень Chrome відкрийте **Lasthavens Addon Manager**. Значок можна закріпити на панелі.

> Якщо завантажили **Source code (zip)**, після розпакування виберіть вкладену папку `extension/`.

## Додавання аддонів

1. Завантажте аддон для **WoW 3.3.5a**.
2. Відкрийте менеджер та імпортуйте ZIP аддона.
3. Увімкніть аддон перемикачем.
4. **Перезавантажте сторінку гри**, щоб застосувати зміни.

Щоб оновити аддон, імпортуйте новий ZIP. Його стан увімкнення збережеться. Вимкнення, оновлення та видалення також потребують перезавантаження сторінки гри.

## Оновлення розширення

Розпакуйте новий реліз у ту саму папку встановлення, відкрийте `chrome://extensions` і натисніть кнопку перезавантаження на картці розширення. Знову відкрийте менеджер і перезавантажте сторінку гри. Розпаковані розширення не оновлюються автоматично.

## Зберігання та сумісність

Файли зберігаються в поточному профілі Chrome. Видалення зберігає ігрові налаштування аддона. Заміна вбудованих папок не підтримується. Сумісність кожного аддона потребує перевірки у грі.

| Обмеження          | Максимум |
| ------------------ | -------: |
| ZIP-архів          |    32 MB |
| Розпакований архів |    64 MB |
| Один файл          |    16 MB |
| Бібліотека аддонів |    96 MB |

**Експериментальна версія:** автоматичні локальні перевірки пройдено; повна сумісність встановленого розширення з поточним клієнтом і сторонніми аддонами ще перевіряється. [Стан перевірок](VALIDATION.md).
