# Lasthavens Addon Manager

[en](../README.md) · [ru](../docs/README.ru.md) · [uk](../docs/README.uk.md) · [es](../docs/README.es.md) · [fr](../docs/README.fr.md) · [pt_BR](../docs/README.pt-BR.md)

Локальный менеджер аддонов для Lasthavens 3.3.5a. Импорт ZIP, включение и отключение, обновление повторным импортом, экспорт и удаление. Изменения применяются после перезагрузки игры.

Скачайте ZIP из Releases, распакуйте, откройте chrome://extensions, включите режим разработчика и нажмите «Загрузить распакованное расширение». Выберите папку с manifest.json. Откройте менеджер через значок расширения, импортируйте ZIP, включите аддон и перезагрузите игру.

Файлы хранятся в текущем профиле Chrome. Удаление сохраняет игровые настройки аддона. Замена штатных папок не поддерживается. Совместимость каждого аддона требует проверки в игре.

UI: English, Українська, Русский, Español, Français, Português.

ZIP ≤ 32 MB · unpacked ≤ 64 MB · file ≤ 16 MB · library ≤ 96 MB.
