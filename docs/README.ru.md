# Lasthavens Addon Manager

[English](../README.md) · [Українська](README.uk.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Français](README.fr.md) · [Português](README.pt-BR.md)

Локальный менеджер аддонов для Lasthavens 3.3.5a. Импорт ZIP, включение и отключение, обновление повторным импортом, экспорт и удаление. Изменения применяются после перезагрузки игры.

![Lasthavens Addon Manager — English interface](images/manager-en.png)

## Установка в Chrome

1. Откройте [Releases](https://github.com/Jamba777/lasthavens-addon-manager/releases) и скачайте архив `lasthavens-addon-manager-<version>.zip` из раздела **Assets**.
2. Распакуйте ZIP в папку, которую будете хранить на компьютере.
3. Откройте `chrome://extensions` в Chrome.
4. **Включите «Режим разработчика» (Developer mode) в правом верхнем углу.**
5. Нажмите **«Загрузить распакованное расширение» (Load unpacked)** и выберите папку с `manifest.json`.
6. Откройте меню расширений Chrome и выберите **Lasthavens Addon Manager**. Значок можно закрепить на панели.

> Если скачали **Source code (zip)**, после распаковки выберите вложенную папку `extension/`.

## Добавление аддонов

1. Скачайте аддон для **WoW 3.3.5a**.
2. Откройте менеджер и импортируйте ZIP аддона.
3. Включите аддон тумблером.
4. **Перезагрузите страницу игры**, чтобы применить изменения.

Для обновления аддона импортируйте новый ZIP. Его состояние включения сохранится. Отключение, обновление и удаление тоже требуют перезагрузки страницы игры.

## Обновление расширения

Распакуйте новый релиз в прежнюю папку установки, затем откройте `chrome://extensions` и нажмите кнопку перезагрузки на карточке расширения. Снова откройте менеджер и перезагрузите страницу игры. Распакованные расширения не обновляются автоматически.

## Хранение и совместимость

Файлы хранятся в текущем профиле Chrome. Удаление сохраняет игровые настройки аддона. Замена штатных папок не поддерживается. Совместимость каждого аддона требует проверки в игре.

| Ограничение         | Максимум |
| ------------------- | -------: |
| ZIP-архив           |    32 MB |
| Распакованный архив |    64 MB |
| Один файл           |    16 MB |
| Библиотека аддонов  |    96 MB |

**Экспериментальная версия:** автоматические локальные проверки пройдены; полная совместимость установленного расширения с текущим клиентом и сторонними аддонами ещё проверяется. [Статус проверок](VALIDATION.md).
