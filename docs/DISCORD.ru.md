**Lasthavens Addon Manager — расширение Chrome для локальных аддонов**

Подготовил экспериментальный менеджер аддонов для браузерного клиента Lasthavens 3.3.5a.

Возможности:

- импорт аддонов из ZIP, включая архивы с несколькими аддонами;
- список с версиями, размером и зависимостями;
- включение и отключение отдельным переключателем;
- обновление повторным импортом, экспорт ZIP и удаление;
- украинский, русский, английский, испанский, французский и португальский.

Файлы хранятся локально в профиле Chrome. Изменения применяются после перезагрузки игры. Штатные аддоны по-прежнему управляются через библиотеку игры.

Установка: скачать ZIP из Releases → распаковать → chrome://extensions → режим разработчика → «Загрузить распакованное расширение» → выбрать папку с manifest.json.

Версия 0.2.0 экспериментальная. Импорт, интерфейс и загрузчик прошли автоматические локальные проверки. Полная совместимость установленного расширения с текущим клиентом и каждым сторонним аддоном пока не подтверждена. Если сообщаете об ошибке, укажите версию расширения, название/версию аддона и текст ошибки; пароли и данные аккаунта не нужны.
