# Lasthavens Addon Manager

[en](README.md) · [ru](docs/README.ru.md) · [uk](docs/README.uk.md) · [es](docs/README.es.md) · [fr](docs/README.fr.md) · [pt_BR](docs/README.pt-BR.md)

Local addon manager for Lasthavens 3.3.5a. Import ZIP, enable or disable addons, update by importing again, export and remove. Changes apply after reloading the game.

Download the release ZIP, extract it, open chrome://extensions, enable Developer mode, select Load unpacked and choose the directory containing manifest.json. Click the extension icon. Import a ZIP and enable the addon. Reload the game page.

Files stay in the current Chrome profile. Removing an addon preserves its game settings. Built-in addon folders cannot be replaced. Compatibility with every addon is not guaranteed.

UI: English, Українська, Русский, Español, Français, Português.

ZIP ≤ 32 MB · unpacked ≤ 64 MB · file ≤ 16 MB · library ≤ 96 MB.
